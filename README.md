# Personal Finance Dashboard

A local Streamlit app to add expenses, view totals, and visualize spending by category. Data is saved to a local CSV file.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Privacy
The app stores data in `expenses.csv` in this folder. Do not commit personal financial data to GitHub. Add `expenses.csv` to `.gitignore` before using it with real information.
